# Nawasrah Business Manager - نظام إدارة مؤسسة نواصرة التجارية

تطبيق آيفون متكامل لإدارة المبيعات، المحاسبة، نقطة البيع (POS)، الطلبات، الموردين والمخزون المصمم خصيصاً لمؤسسة نواصرة التجارية.

---

## 🌟 مميزات التطبيق الرئيسية

- 📱 **واجهة تجربة آيفون حقيقية (iOS Simulation Container)**:
  - دعم Dynamic Island للإشعارات الحية.
  - شريط تنقل سفلي زجاجي سريع ومريح.
  - واجهة داكنة مريحة للعين (Dark Mode) مع دعم كامل للغة العربية والـ RTL.

- 🛒 **نقطة البيع (POS) المتقدمة**:
  - البحث الفوري بالاسم والباركود.
  - حساب ضريبة المبيعات الأردنية (16%) والمبلغ المتبقي للزبون تلقائياً.
  - تعليق الفواتير وإكمالها لاحقاً.

- 📦 **إدارة المخزون الذكية والحجز الذري**:
  - متابعة الكمية المتوفرة والمحجوزة بدقة.
  - جرد المخزون، حركة الأصناف، وتنبيهات إعادة الطلب.
  - خوارزمية منع الحجز المضاعف للطلبات.

- 📊 **المحاسبة المزدوجة التقارير المالية**:
  - دليل الحسابات الشامل (Chart of Accounts).
  - تقارير الأرباح والخسائر، التدفقات النقدية، وورديات الصندوق.
  - إدارة ديون العملاء والتزامات الموردين.

- 🧪 **مختبر الاختبارات الآلية (Automated QA Testing Suite)**:
  - وحدة اختبارات داخلية مدمجة لتأكيد صحة العمليات الحسابية وحفظ المخزون.

---

## 🚀 كيفية تشغيل المشروع

1. **تثبيت الحزم (Dependencies)**:
   ```bash
   npm install
   ```

2. **تشغيل بيئة التطوير**:
   ```bash
   npm run dev
   ```

3. **التحقق من صحة الكود والـ TypeScript**:
   ```bash
   npm run lint
   ```

4. **بناء المشروع للإنتاج**:
   ```bash
   npm run build
   ```
