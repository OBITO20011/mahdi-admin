# رفع صور المنتجات والنكهات حسب رمز الصنف

حزمة منفصلة عن الهوية، من main `f95ff045`. السقف 214 كما هو: لا migration أو RPC جديد أو تعديل صلاحيات أو حسابات، ولا اتصال مستضاف أو نشر. تنتظر مراجعة المالك بعد CI الكامل على SHA النهائي في PR.

## الاستخدام

1. بعد إدخال المنتجات افتح «بداية التشغيل» أو «المنتجات» ثم «رفع صور المنتجات حسب الرمز». تبقى الأداة متاحة بعد الإنهاء لنفس أدوار تعديل المنتجات.
2. اسم الملف دون الامتداد يساوي رمز الصنف أو النكهة: `SUG-10.jpg` أو `PRG-BBQ.jpg`. المقارنة تزيل الفراغات الطرفية، وتتجاهل حالة الأحرف، وتوحّد الأرقام العربية والهندية. لا مطابقة بالاسم.
3. اختر صوراً متعددة أو مجلداً إن دعمه المتصفح. الصيغ JPG/PNG/WebP، حتى 5MB للملف الأصلي و500 ملف للدفعة. المعاينة محلية قبل أي رفع؛ تعرض الصورة واسم المنتج/النكهة ورمزه، وغير المطابق والتكرار والأصناف النشطة بلا صورة.
4. احذف التكرار أو صححه قبل الرفع. الصور الحالية تُتخطّى افتراضياً؛ «استبدال» اختيار صريح لكل سطر.
5. «تأكيد رفع الصور المطابقة» يشغّل عاملين مع تقدم ونتيجة ناجح/فاشل/متخطّى. الضغط إلى JPEG أقل من 300KB وضلع لا يتجاوز 1200px، مع تثبيت اتجاه EXIF في البكسلات.
6. «أعد المحاولة للفاشل» يعيد الفاشل فقط. بعد إعادة فتح الصفحة اختر الملفات نفسها؛ بصمة المحتوى وربطها بالمشروع والحساب يمنعان إعادة رفع المحفوظ.

لا تغلق المتصفح أثناء الرفع. عند انقطاع الرد لا تمسح سجل المتصفح. «تحقق من الرفع السابق ونظّف غير المحفوظ» يفحص المرجع المحفوظ قبل الحذف؛ الحالات المجهولة تبقى للاستئناف على المسار نفسه. «تنزيل تقرير الرفع والتنظيف» يحدد الملفات والمسارات المعلقة للمراجعة. لا تُحذف صورة ذات مرجع رئيسي أو ثانوي، حتى لو انتقل مرجعها إلى صنف آخر. عند تعذر حسم الحالة يُراجع المطوّر التقرير قبل تنظيف يدوي.

## العقد المستخدم

- قارئ المنتجات الحالي مرقّم من الخادم، ويشمل النكهات؛ تُقرأ كل الصفحات ويُرفض الجرد غير المكتمل أو المتغير أثناء التحميل.
- الرفع عبر `product-images.service` الحالي؛ يُحفظ قصد الرفع محلياً قبل أول كتابة Storage. لا أسرار أو ملفات صور في سجل الاستئناف.
- كاتب الصورة هو `set_product_primary_image(uuid,text)` الموجود، والذي تستعمله دوال حفظ المنتج والنكهة الحالية داخلياً. لا يُعاد إرسال نموذج المنتج أو أسعاره أو تكلفته. هذا يحافظ أيضاً على القيم الكبيرة وحقول البيع الفارغة التاريخية.
- فحص الجلسة والصلاحية قبل العمل، وقراءة جديدة للرمز والصورة قبل الحفظ. قفل متصفح يمنع دفعتين للحساب والمشروع نفسيهما. التفويض النهائي وعقد القفل داخل كاتب الصورة الحالي كما هما؛ لم تُضف مقارنة ذرية جديدة لتعديل يدوي متزامن من نموذج آخر.
- فشل الحفظ المثبت ينظف المرفوع غير المرتبط. فشل النقل لا يُعد إثبات تراجع: يُحفظ للاستئناف والتحقق، ويُفحص كل مرجع للصورة قبل أي تنظيف.

## الأدلة المحلية

التفصيل في [BULK_PRODUCT_IMAGES_LOCAL.json](BULK_PRODUCT_IMAGES_LOCAL.json):

- 1520 اختبار إدارة و197 اختبار متجر؛ TypeScript وlint الصارم والبناءان وSEO المعزول ناجحة، وGitleaks صفر.
- 14 حالة متصفح للميزة و104 للشاشات المتأثرة، على Chromium وWebKit، بما فيها الهاتف وRTL والقصّ والتعارض والنماذج السابقة.
- قاعدة محلية جديدة حتى 214، بحسابات Auth/MFA وهمية وStorage وRPC فعليين. تسعة أدوار/حالات، مع رفض anon وبلا كتابة للمرفوضين؛ الأربعة المخوّلون وفق العقد الحالي نجحوا.
- الرفع والنكهة والفشل في الوسط والتنظيف وإعادة المحاولة وفقدان الرد والاستئناف عبر إعادة الفتح مثبتة. 12 ملف Storage مرتبطة بمراجعها، صفر يتيم وصفر تعدد للصورة الرئيسية؛ 104 جداول محمية مطابقة قبل/بعد.
- بيانات المنتج كاملة بقيت مطابقة، حتى تكلفة `9007199254740993` وحقل بيع فارغ، وتكلفة WAC الكسرية في أصناف الاختبار.
- أدلة SDK جديدة غير مسقطة: 157 فحص جداول و543 استدعاء RPC. رفض كاتب الصورة القديم يستخدم `P0001` برسالة عربية للصلاحية؛ فحوصه الوظيفية منفصلة عن استدعاءات الحمولات المحايدة.
- دليل صاحب المحل وHTML، وورقة التشغيل وHTML، وREADME القوالب محدّثة. طباعة A4: الدليل 10 صفحات وورقة التشغيل صفحتان. ملفات Excel وأدلة الإصدار السابق لم تُعدّل.

بروفة بدء واحدة لم تكتمل قبل مهلة الحاويات الأصلية أثناء تشغيل الفحوص الثقيلة بالتوازي؛ لم تُحسب نجاحاً. إعادة بيئية واحدة بنفس الكود والمهلة نجحت. لا زيادة للمهل أو إعادة المحاولات أو تخفيف الاختبارات. أُصلح نطاق بيانات SDK الاختبارية لإعطاء استعلام مرجع الصورة الجديد عنواناً محلياً وهمياً. الطبقة العكسية الجديدة تقبل البايتات المحددة فقط، وتحافظ على أدلة الاختبارات التاريخية دون تعديلها؛ أدلة الوصول الحالية تغطي الإضافة الفعلية كلها.

CI الكامل شرط الاعتماد، ثم يتوقف العمل إلى قرار المالك. لا أمر ترقية للقاعدة لهذه الحزمة.
