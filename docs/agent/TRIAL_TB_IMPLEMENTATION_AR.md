## النطاق

1. G1 معاينة خادمية للمرتجع والفحص والتبديل، بلا كتابة أثناء المعاينة.
2. G2/G3 استبدال مفحوص ذري: إصدار البديل بالتكلفة الحالية أولاً، ثم استرداد السليم بالتكلفة التاريخية للقطعة الفعلية؛ المعيب وحده نهائي أو للمورد.
3. G4 صنف آخر: أصل مسدد، وطرد كامل أو باكيت بيع أصلي مستقل؛ مقابل داخلي غير نقدي، وفرق المال الفعلي فقط كاش/CliQ؛ لا دين جديد أو بيع جزئي مستتر.
4. G5 كشف تالف مرقم ومفلتر بالحالات الكمية الثلاث، ومستند مرتبط وحجم تاريخي وصافي خسارة الفترة، وقيم المالك وحده.
5. G6 خصم مورد بالقيمة التاريخية الكاملة وبحد مستحق مؤيد، مع سجل ذمة ومنع ازدواج الاستلام/الرفض/الخصم.
6. معالج عربي واحد، ورد المال الافتراضي حسب الأصل ضمن الأهلية، والدين الخاص بالفاتورة أولاً؛ القدرات القائمة النادرة في متقدم.

## قيود ثابتة

- لا تغيير للحركات السابقة أو migrations 001–214 أو مراجعها؛ لا backfill.
- نفس الأدوار والنشاط وMFA، وإخفاء قيم المالك من DTO غير المالك.
- لا رد مال لباكيت من طرد؛ استثناء التبديل المعيب القائم بنفس الصنف فقط.
- لا كاش أو CliQ وهمي للمقابل الداخلي، ولا مصروف/افتتاحي مصطنع لتخفيض المورد.
- الأقفال وفق ترتيب الطلب/الوردية/كل المنتجات، مع إعادة التحقق تحت القفل؛ replay يطابق كامل الطلب، وفشل أي جزء يتراجع كلياً.
- لا اتصال بمشروعات أو نشر أو تنفيذ أمر المالك. لا ت-ج. يعود PR التنفيذ لاعتماد المالك قبل دمجه.
