- مستويان: طرد ومحتواه باسم الوحدة. اسم الطرد المعروض «طرد» حتى للبيانات
  القديمة المحفوظة «باكيت»،دون إعادة كتابة المنتج أو الكمية.
- نموذج واحد: الاسم/القسم/الباركود،محتوى الطرد وخيار بدون طرد N=1،وجدول
  شراء/بيع × طرد/وحدة بالتحويلات الحالية. الطردان متساويان افتراضياً؛الاختلاف
  الحالي محفوظ ومتقدم. حقول التغليف/الصورة/الوصف/الماركة/الحدود مطوية.
- حارس170 والتعارض وإعادة التطبيق ومسارات171 باقية. الربح التقريبي بسعر
  الشراء المقترح موسوم،ومتوسط التكلفة الحالي مستقل. لا تغيير لحمولة الحفظ
  أو كاتب الاستلام أو WAC أو حساب الكلفة أو سعر البيع تلقائياً.
- الاستلام المباشر وPO يبقيان زري الوحدة/الطرد،والكميات والإجمالي والتحويلات.
  المحتوى سطر مع تعديل،لا قائمة نوع طرد،والخصم تحت متقدم.
- آخر سعر يُقرأ من دليل الاستلام المعتمد،كما أجاز15؛لا كتابة تلقائية لافتراضي
  المنتج. اقتراح متأخر لا يمحو سعر المستخدم أو الكمية؛فشل القراءة مسمى.
- ارتفاع الشراء مقارنة بنفس أساس الوحدة يظهر الربح التقريبي وتحذير الخسارة.
  تعديل البيع يعيد استخدام نموذج المنتج المتفائل داخل نافذة محلية،ويُبقي سطر
  الاستلام. أدوار حفظ المنتج الحالية owner/admin/manager/warehouse_keeper فقط.
