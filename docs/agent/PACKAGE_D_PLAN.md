## الشاشات الثلاث

1. **الكاشير:** اختيار «قطعة / طرد من صنف واحد»، سلة واضحة بالوحدات والسعر من السيرفر، ثم `create_pos_sale_v2` بدلاً من V1. تُحفظ نسخة الطلب والمفتاح قبل أي انتظار؛ النتيجة المجهولة توقف بيعاً جديداً وتُظهر «استرجاع المحاولة» بنفس الهوية بعد reload، لا retry تلقائي أو مفتاح بديل. النجاح يُطابق الطلب والنتيجة، ثم الإيصال والمرتجع/الاستبدال الحديث.
2. **تركيب الطرد داخل الكاشير:** نافذة تعرض الأصناف المسموحة والمخزون في مستودع الكاشير، عدّاد «المختار / سعة الطرد»، اختيار النكهات والكميات وتعديل كل طرد مستقلاً؛ لا إضافة قبل اكتمال السعة. ترسل `configurable_parcel` مع configuration/revision والمكونات، دون أسعار أو تكلفة مخترعة.
3. **إعداد الطرود بالإدارة:** للمالك؛ اختيار العائلة، نمط الطرد، تفعيله، عدد القطع والنكهات المسموحة، مع حفظ واضح. حالة الميزة OFF / OWNER_PILOT / ENABLED مع تأكيد وأثرها على عمليات البيع الجديدة. قرار التسليم: ENABLED للمتجر والكاشير، لا تشغيل Production الآن.
