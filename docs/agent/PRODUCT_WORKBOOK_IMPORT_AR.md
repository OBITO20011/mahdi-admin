# قالب المنتجات والنكهات — سقف219 بلا تغيير قاعدة

هذا التغيير مبني فوق PR #63 غير المدموج، وليس بديلاً عن اعتماده. يستخدم الدوال الموجودة؛ لا migration أو تعريف RPC جديد. أمثلة الملف وهمية فقط.

## صاحب المحل: من الملف إلى الجرد

1. من «بداية التشغيل» ← المنتجات نزّل القالب، أو استخدم `docs/handover/templates/المنتجات.xlsx`. احذف مثال ورقتَي «المنتجات» و«النكهات». لا ترفع ورقتَي التعليمات/المراجعة و«بعد الاستيراد» منفصلتين.
2. املأ المعلومات الثابتة مبكراً. استخدم الأقسام والوحدات والعلامات الموجودة، ورمز الوحدة مثل PKT/CTN عند تشابه الأسماء. عدّل قوائم المساعدة في Excel لتوافق مرجعك؛ المعاينة والفاحص هما التحقق الفعلي.
3. اختر «طرد» أو «باكيت مفرد» أو «الاثنين». للمفرد فقط حجم طرد البيع1؛ طرد الشراء يبقى بحجمه. سعر الباكيت محسوب من سعر طرد البيع/محتواه بتقريب الفلس نفسه؛ يجب أن يطابق السعر المدخل. ليس سعراً مستقلاً. الرؤوس القديمة وعمود «يُباع بالطرد فقط» القديم مقبولة، والقالب الجديد لا يكرره.
4. للعائلة: صف أساسي بلا باركود أو مخزون في المنتجات، وصف لكل نكهة في «النكهات» يذكر رمز الأساسي. النكهة ترث الأسعار والتكلفة وطريقة البيع. لا تُنشأ نكهات بعدد يفوق30 في العائلة. رمز النكهة الفارغ يولّد رمزاً حتمياً مقروءاً يظهر قبل الحفظ؛ التصادم يمنع الحفظ.
5. اكتب الباركود والرموز كنص قبل لصقها. إذا ضاعت أصفارها أو أرقامها الطويلة بسبب Excel فلن يعيدها تغيير التنسيق؛ ارجع للأصل. لا تُصلح الأداة الأرقام بالتخمين.
6. شغّل فاحص الملفات المحلي حسب [دليله](../operations/GO_LIVE_FILES_CHECK_AR.md)، ثم اختر الملف في الواجهة وراجع الرموز النهائية والأخطاء. لا تضع مخزوناً تجريبياً لإسكات تنبيه «صنف بلا مخزون».
7. اضغط «حفظ المنتجات والنكهات ومطابقتها». عند انقطاع: الجهاز والمتصفح والملف نفسه، ثم «استئناف المحاولة ومطابقة بياناتها». لا تمسح بيانات المتصفح أو سجل المحاولة ولا تبدأ ملفاً مختلفاً. شغّل الاستيراد من جهاز ومتصفح واحد فقط؛ قفل المتصفح يمنع نافذتين من الكتابة على السجل نفسه، والمتصفح القديم يُرفض قبل الإنشاء. لا يوفر هذا قفلاً بين جهازين. الاكتمال لا يظهر قبل القراءة المطابقة.
8. املأ المخزون بعد جرد فعلي قرب D−1/يوم التشغيل، بالباكيت. تركه فارغاً يعني تعريفاً برصيد صفر وتنبيهاً فقط. بعد اكتمال التعريف نزّل ملف «البضاعة الموجودة» واستورده من بطاقته المحروسة. الكمية تتحول إلى طرود **الشراء** وباكيتاتها؛ لا تستعمل استلام شراء للمخزون الافتتاحي.
9. عند اختلاف المستودع تُنزّل ملفات منفصلة، اختر مستودع كل ملف في بطاقة الجرد. الوجهة الفارغة تتطلب الاختيار هناك. لا تكرر كميةً موجودة في ملف البضاعة وعمود المخزون معاً؛ الفاحص يرفض المصدرين.
10. بعد إدخال المنتجات: رفع مجلد الصور؛ اسم الملف = رمز الصنف النهائي، وصورة مستقلة لكل نكهة وخلفية فاتحة. إعداد السماح بالطرد المشكّل يُراجع من إعداداته الحالية بعد إنشاء العائلة، ولا يفعّله هذا الملف.

## مطابقة شاشة إنشاء المنتج

| حقل الشاشة | القالب/القاعدة |
|---|---|
| الاسم/رمز الصنف/الباركود/القسم | أعمدة مباشرة؛ الرموز تُطبع بالحروف الكبيرة كما يفعل حارس108 |
| الوحدة/طرد الشراء/محتواه/طرد البيع/محتواه | الأعمدة الحالية بأسماء أوضح؛ تبقى الرموز القديمة مقبولة |
| سعر شراء الطرد/تكلفة الباكيت/سعر بيع الطرد | دنانير بثلاث خانات، تمر إلى العقود القائمة كنص فلس؛ لا تحويل مال كبير إلى Number |
| طريقة البيع/سعر بيع الباكيت | طريقة صريحة وسعر مشتق مطابق، لا تخزين سعر مستقل أو تغيير تسعير |
| العلامة/الوصف | عمود اختياري، الفارغ بلا علامة/وصف؛ لا إنشاء مرجع جديد تلقائياً |
| حد الطلب/سقف المستودع | حد أدنى/أقصى **بالباكيت** في القالب؛ الشاشة تعرضهما بالطرود وتحولهما عند الحفظ |
| المستودع | وجهة الجرد الافتتاحي في الملف المصدر؛ ليس ربطاً ثابتاً جديداً للمنتج |
| الصورة | المجلد حسبSKU بعد اكتمال التعريف؛ لا URL صورة في الاستيراد |
| النكهات | ورقة مستقلة، أسعار موروثة، الأساسي بلا مخزون؛ باركود النكهة اختياري |
| الرصيد | تعريف أولاً بصفر، والجرد الافتتاحي من `apply_inventory_opening_setup` لاحقاً |
| نشط/إعداد المشكّل | المنتج الجديد نشط؛ السماح بالمشكّل من مساره الحالي، لا افتراض جديد |

من نموذج المنتج نفسه يمكن إدخال «باركود النكهة (اختياري)» أو مسحه بالكاميرا. التكرار داخل المسودات أو مع الأصناف القائمة يمنع الإنشاء. إذا حُفظت العائلة وتعذّر تأكيد الباركود، يظهر استكمال العائلة المحفوظة ولا يعاد إنشاؤها. إذا تعذر حفظ سجل الجهاز بعد الإنشاء، لا تغلق النافذة؛ أصلح مساحة التخزين واستكمل. إذا فُقدت النافذة قبل سجل دائم، يراجع المطوّر العائلة من تفاصيلها بالـUUID؛ لا يعاد إنشاؤها.

## عقد التنفيذ والاستئناف

`import_go_live_products_v1` للصف العادي، و`create_product_family_with_flavors_v2` للعائلة؛ ثم `update_product_master_v5` للتوصيف والرموز و`update_product_flavor_v2` لباركود نموذج الإنشاء. كلها بحساب المتصل وحراسة الإصدار القائمة؛ لا service_role. طريقة النكهة الموروثة تمر NULL في v5 ولا تُعدل.

**ليست كل الدفعة معاملة واحدة.** إنشاء العائلة ذري، ثم تثبيت المعرفات مرحلة قابلة للاستئناف. يُحفظ journal مرتبط بالمستخدم/المشروع/بصمة الخطة، ومفتاح SKU مؤقت فريد قبل أي إنشاء. تثبت UUIDs قبل تغيير الأسماء، وتُرفض التغييرات المتزامنة. ضياع جواب الإنشاء لا يغيّر المفتاح. تعاد قراءة كل الحقول النهائية؛ لا «اكتمل» ولا تصدير جرد قبل التطابق. إعادة المكتمل تقرأ فقط. المخزون لم يُكتب في هذه المراحل.

الحدود: الملف5MB/5000صف كما في القارئ، وعائلة30نكهة. النموذج الجديد يعالج الصفوف والعائلات تسلسلياً؛ الاستيراد القديم العادي يبقى بدفعات100 وبفرع الحفظ/المفاتيح نفسه. لا تمسح journal لمحاولة ناقصة.

## إثبات محلي وحدوده

- اختبارات parser/فاحص/استئناف، وحالات باركود ورموز مكررة ومفقودة وسعر مشتق غير مطابق وأصفار بادئة.
- `scripts/testing/run-product-template-existing-rpcs.mjs`: قاعدة219/180 معزولة، الخدمة الفعلية موصولة بناقل SQL محلي ثابت بفاعل authenticated/owner/AAL2 وهمي؛ العائلة والرموز والـCAS والجواب المفقود وإعادة المكتمل والجرد المحروس. هذا إثبات للدوال والخدمة، وليس اتصال Auth مستضافاً.
- متصفحا Chromium/WebKit ومعاينة390؛ camera mock محلي، لا إذن كاميرا أو إرسال حقيقي.
- ملف XLSX مؤلف بـArtifactTool، RTL وfreeze وvalidation وصيغ مخبأة، أعيد فتحه بقارئ التطبيق. لم تُؤتمت نسخة Excel الأصلية. خلل renderer Windows بعد كتابة الصور لا يُعد نجاح Excel أصلياً؛ الخلايا والباركود تحققت مستقلاً.

لا SQL/migration أو تعديل مالي/صلاحيات أو اتصال مستضاف/نشر. ملفات المالك الأصلية لم تُستورد ولم تُعدّل. الأدلة الحالية منفصلة عن دليل قالب214 التاريخي؛ لا يعاد وسم تجربة214 على أنها219.


أدوات RESET219 وتبعياتها113 تبقى بايتاً ببايت. قرّاء الأدلة التاريخية في الاختبارات فقط يستخدمون إسقاطاً ببصمات دقيقة، ولقطة يعاد إنتاجها بتشغيل وحدات Git63 الأصلية في مجلد مؤقت بلا شبكة. أي مصدر أو وسيطة قراءة غير معتمدة تُرفض؛ جرد219 الحالي و181قراءة/598استدعاء يُفحصان دون إسقاط. لا تُعدّل أدلة SQL/الأدوار التاريخية أو المقارنات لتجاوز اختلاف.
