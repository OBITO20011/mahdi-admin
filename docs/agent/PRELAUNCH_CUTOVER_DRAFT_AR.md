# مسودة القطع — لا يُدمج قبل يوم التشغيل

الحزمة ب بقرار المالك2نوفمبر: قلب المفتاح الموجود `PRELAUNCH_TRIAL_OPEN` فقط إلى `false`، مع إبقاء السياق والفرع والبيئات وكل CSP والصلاحيات دون تغيير. لا تنفيذ للنشر أو Access أو RESET من الوكيل.

دمج هذه المسودة مبكراً يوقف نشر إصلاحات التجربة النهائية؛ لذلك تبقى **Draft دون دمج**. زُومن الفرع بدمج main الفعلي `376293af705837201e4c94b66967337baf524af6` وفق تفويض4نوفمبر. حفظت البطاقة وخطة القطع محتوى #60 و#61 و#62 المعتمد: تجهيز الرأس وCI في D−1، ثم **يوم القطع فقط، الخطوة2 في §2 من البطاقة، قبل الحظر المثبت والنسخة الفاصلة**؛ بإذن المالك يُدمج PR58 ويكتمل CI main وتُحدَّث نسخة الناشر قبل توقيع التجميد. تُغلق المعاينات وhash URLs والأجهزة والمستهلكات فعلياً قبل وقت آخر كتابة والنسخة؛لا يُستعمل ترتيب «بعد النسخة الفاصلة» القديم. لا تغلق الراية الملفات المنشورة أو PWA القديمة؛ Access وإزالة النشرات تبقيان إلزاميتين.

الاختبار يستدعي الأوامر الفعلية لكل تطبيق: بناء التجربة مرفوض، وفحص ملف dist سابق بعلامات التجربة مرفوض، ورفع `--check` مرفوض قبل أي Wrangler، حتى مع override بيئي أو علم isolated. production وstaging يبنيان فعلياً ويجتازان verify-dist، ورفض origin معاكس وتغيير CSP وفحص SEO المعزول باقٍ. لا حذف لحالات مالية أو تخفيف لبوابة CI. SEO التجربة المقطوعة يُرفض قبل fetch.

ورقة يوم التشغيل Markdown/HTML مطابقة لنسخة main الحالية، بما فيها إعادة البروفة على النسخة الفاصلة ونافذة RESET219 والاستئناف بعيداً عن03:00عمّان وpg_cron وAuth/TOTP والوجهات الفعلية. دُمج PR61 الخاص بمرجعD−1 في main؛حُفظ دليله وبصماته وخطوة النسخ المحلية قبل البروفة كاملة. لم يُستبدل مرجع المالك ضمن هذه المزامنة. إزالة السياق نهائياً لاحقاً بقرار وPR مستقلين. لا دمج PR58 في هذا التفويض؛المطلوب مزامنة وفحص فقط.
