## نقطة البداية الحالية

## إضافة المالك: تشخيص تحضير الترقية

ضمن PR ت-ج نفسه: apply215 يفحص token الطرفية المرفوعة قبل manifest والمهام وكلمة المرور والاتصال. عدم الرفع يخرج بالكود `UPGRADE_BACKUP_TASKS_NOT_VISIBLE_RUN_AS_ADMINISTRATOR`؛ لا يتطلب إعادة تسجيل مهام صحيحة. جرد المهام يحتفظ بحراس المسار والحالة والاستدعاء الخمسة، ولا يحاول رفع الصلاحية تلقائياً. تصنيف مشترك للتحضير يعرض أكواداً مسموحة فقط، دون stdout/stderr خام أو معاملات assertion. محول216 سيستخدم نفس الحارس والتصنيف.

الدليل المحلي: 7 اختبارات ناجحة تشمل عدم الرفع قبل أي قراءة أخرى، المهام الخمس الصحيحة، مساراً خاطئاً، أخطاء PowerShell والمهلة وJSON، منع تسرب قيمة اصطناعية، وترتيب run215 مع إعفاء dry-run وverify-only من جرد المهام. strict lint للملفات المتغيرة ناجح. فحص token الحقيقي على هذه الطرفية المحلية غير المرفوعة أعاد الكود المتوقع؛ لم يُستدعَ Get-ScheduledTask أو أي اتصال قاعدة. أول فحص اختبارات رفض فقد الاستدعاء الحرفي لـoperationalManifest؛ حُفظ الاستدعاء الفعلي الافتراضي وأُعيدت الاختبارات دون إضعاف الحارس.

فحص أنواع المشروع الكامل ناجح بعد تثبيت نوع نتيجة منفّذ PowerShell كـstdout/stderr نصيين بدلاً من تسريب نوع ChildProcess إلى بدائل الاختبار. إعادة الاختبارات السبعة وstrict lint ناجحة. اختبار أمر dry-run الفعلي بمجلد وهمي مفقود أعاد `UPGRADE_PREPARATION_FILE_NOT_FOUND` فقط، مع exitCode=1 ودون كشف المسار.
