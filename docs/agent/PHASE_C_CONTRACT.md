# المرحلة ج — تفويض المالك 2026-10-19

المصدر: طلب المالك المباشر في هذه المحادثة بعد مراجعة تقارير ب. يحل هذا
التفويض محل توقف ب فقط؛ لا يفتح Production أو Frankfurt أو النشر أو الأسرار.
كاتب واحد وworktree مستقل لكل حزمة، commit/PR مستقل، Gitleaks صفر، CI كامل
لنفس SHA قبل الدمج ثم CI main وتقرير عربي. محلياً types/lint/الوحدات والمتأثر
فقط؛ لا تكرار الحزم الثقيلة بلا دليل جديد. الأوامر المستضافة للمالك لا ينفذها الوكيل.

## ترتيب ملزم

1. إثبات runtime لتجاوز update_product_master وv2 لحارس171 ثم سحب EXECUTE
   المباشر من أدوار العميل في migration مستقلة؛ تبقى الدوال والنداءات الداخلية.
   اختبار SQLSTATE42501 والحديثv4؛ مراجعة بقية كتّاب تقرير UNEXPOSED واقتراح السحب.
2. إصلاح المقبوض، كل طالع بطاقة الوردية ومنها الموردون، وخسائر التلف في الربح.
3. سجل مبيعات شامل بنفس أدوار قراءة الطلبات وتطابق الرئيسية، ثم آخر خمس مبيعات.
4. قاعدة الطرد الواحدة، نموذج المنتج13/15، الاستلام14/16 والإيصال17.
5. التنقل والدرجRTL، الرئيسية المضغوطة، الصندوق داخل/طالع والتقرير المطبوع.
6. المتجر19، بلا تغيير payload أو التسعير.
7. التصحيحات الأربع داخل⋯ من نفس المستند، بمعاينة read-only وسبب وkey وحراس
   الوردية والتبعيات والأدوار الحالية، بلا توسيع صلاحيات.
8. تصميم قصير للبند20 «بيتباع بالطرد بس»، ثم توقف إلزامي لمراجعةClaude.
9. الاستبدال والتالف ح8 بعد التصميم المعتمد؛ لا تجاوز لتوقف البند8.

## حسم المال والتصميم

- خسائر التلف بتكلفة الحركة/WAC وقت الخصم، من يوم التشغيل فقط؛ لا اشتقاق تاريخي.
  يدخل تلف المحل والنهائي مرة واحدة، ويفصل خسارة مرتجع121 المحتسبة أصلاً:
  المثال خسارة60 لا120. القاعدة التشغيلية فارغة حسب إفادة المالك، لا تحقق مستضاف.
- المعلق يعود بقيمته التاريخية وقد يغير المتوسط (مثال150). المعلق ليس خسارة؛
  تعاد تصنيف الخسارة الضمنية عند التعليق وتثبت عند الرفض فقط، مع «منها محتسب أصلاً».
- «أرسله للمورد» داخل المرتجع للمالك فقط؛ أدوار مساري المرتجع الحاليين كما هي.
  ربط المرتجع والمعلق بمنسق ذري واحد، لا طلبين ولا تغيير التسوية المالية121.
- أولوياتP0/P1 في OWNER_SIMPLICITY_REVIEW_AR معتمدة مع تفاصيل المالك13–23.
  حالات العرض: تحميل/صفر بعد قراءة ناجحة/خطأ مسمى/قدرة ناقصة؛ لا صفر يخفي فشلًا.
- سعر الشراء الافتراضي اقتراح؛ آخر شراء من دليل الاستلام أو تحديث ذري مدقق،
  ولا تغيير تلقائي لسعر البيع أو تجاوز حارس171. الكميات والحقول الحالية تبقى.
