# صورة مشاركة المتجر ورأس الجوال

الاسم النصي: **النواصرة لتجارة الجملة والمواد الغذائية**. الشعار الأصلي وكل مشتقاته السابقة محفوظة دون تغيير. صورة المشاركة لا تحتوي رقم هاتف.

- المصدر: `customer-web/brand/social-card.html`، بالعربية وRTL وألوان البيج والبني والذهبي.
- قص العربة فقط من الشعار: x=125، y=110، العرض=470، الارتفاع=330؛ ينتهي قبل الكتابة القديمة. لا يُعدّل ملف الشعار.
- الناتج: `customer-web/public/nawasrah-social-card.jpg`، 1200×630، 57,824 بايت في التوليد المحلي.
- إعادة التوليد من جذر المستودع: `npm.cmd --prefix customer-web run brand:share-image`. يعتمد على Chromium الخاص بـPlaywright، وخط Tahoma على Windows؛ Arial/system fallback عند غيابه. لا تحميل خطوط أو صور من الشبكة. اختلاف الخط المثبّت قد يغيّر البصمة البصرية؛ ملف JPEG المعتمد محفوظ في Git.
- `nawasrah-store-logo.jpg` باقٍ: تستخدمه علامة المتجر وJSON-LD `logo`؛ صورة واجهة المحل باقية في JSON-LD `image`، وصورة المنتج الفعلية باقية في Product JSON-LD. Open Graph وTwitter للصفحات العامة تستخدم صورة المشاركة الجديدة مع أبعادها والنص البديل.
- الاسم على الهاتف سطران بجانب الشعار، والأدوات في صف مستقل؛ من sm فأعلى يظهر الاسم الكامل. اختبارات 360/390/768 على Chromium وWebKit تمنع القص والتمرير الأفقي وتتحقق من بقاء الأدوات.
- مراجعة النصوص تشمل المتجر والإدارة والوصل وmanifest ورسالة اختبار Telegram. عُدّل اسما العرض الاحتياطيان لتسجيل الجهاز فقط، دون تغيير أي حارس أو استدعاء Auth. أسماء الأشخاص التجريبية وعبارات المطابقة الداخلية ليست أسماء تجارية ولا تُعاد كتابتها. الشعار المصوّر هو الاستثناء المعتمد.

المعاينة: [صورة المشاركة](../../../customer-web/public/nawasrah-social-card.jpg)، [رأس iPhone بعرض 360](header-360-webkit.png)، [رأس Chromium بعرض 390](header-390-chromium.png).

لا تعديل SQL أو migration أو صلاحيات أو حساب أو نشر أو تفعيل للتنبيهات. أدلة المصدر القديمة محفوظة كما هي؛ طبقة استعادة دقيقة للتغييرات النصية/البصرية وحدها تتيح استمرار التحقق منها. دليل القراءة الحالي جديد على قاعدة 214 محلية معزولة، وليس ادعاءً بفحص فرانكفورت.
