# ترقية الإيصال العام — 210

هذا أمر المالك بعد دمج الحزمة د وقبول CI على main. الوكيل يجهّز الأوامر والمرجع محلياً فقط؛ لا ينفّذها على فرانكفورت.

210 يضيف للقراءة فقط نوع سطر البيع والكمية والوحدة ومكوّنات الطرد المشكّل من الفاتورة المحفوظة. يبقى نفس الرابط والرمز والصلاحيات؛ لا كتابة مالية أو تغيير أسعار أو تكلفة أو ربح. الفواتير القديمة لا يعاد تصنيفها، وتبقى تسميتها المحفوظة عندما لا يتوفر نوع السطر التاريخي.

يقبل الأمر قاعدة مكتملة حتى208 أو209 أو210. إن كانت حتى208 يطبق209 و210 بالترتيب؛ وإن كانت حتى209 يطبق210 وحده. المرجع المحلي الجديد `local-reference-through210-ready.json` في `C:\Users\TOP\NawasrahFrankfurt\nawasrah-fra-001-138`، والمراجع208/209 تبقى كما هي.

1. افتح PowerShell في المشروع المحدّث إلى main المدموج، ثم المعاينة:

```powershell
Set-Location C:\Users\TOP\mahdi-admin
git pull --ff-only
npm.cmd run frankfurt-owner-upgrade210 -- --dry-run
```

المتوقع: `ok: true`، و`remoteWriteAttempted: false`. هذه مقارنة مراجع محلية محفوظة، فلا تتصل بفرانكفورت. تعرض `pending: ["209","210"]` نسبةً إلى مرجع208 المحفوظ؛ لا تدّعي قراءة سجل القاعدة الحالي. عند التطبيق يحدد الناقص الفعلي. إذا غاب المرجع أو اختلفت بصمته توقف عند التقرير.

2. التطبيق بواسطة المالك:

```powershell
npm.cmd run frankfurt-owner-upgrade210 -- --apply
```

المتوقع: يطلب تأكيد مشروع فرانكفورت وكلمة مرور DB في الطرفية. يفحص التاريخ والمخطط وحالة تعطيل الإشعارات قبل الكتابة، ثم يطبق الناقص ويسجّل كل migration بعد نجاحها. النتيجة `ok: true` و`catalogUnexpectedDifferenceCount: 0`، مع `applied: ["209","210"]` أو `["210"]` بحسب التاريخ. إعادة التشغيل بعد اكتمال210 لا تعيد تطبيقها. لا تعِد ربط المشروع ولا تستخدم `--include-all`.

3. تحقق مستقل للقراءة فقط:

```powershell
npm.cmd run frankfurt-owner-upgrade210 -- --verify-only
```

المتوقع: `ok: true` و`remoteWriteAttempted: false`، سجل172migration حتى210، وتطابق المخطط والصلاحيات و13عضواً فيRealtime وحالة الإشعارات. يتصل للقراءة فقط، ولا يطبق أو يسجّل شيئاً.

إذا ظهرت `ok: false`، احتفظ بمسار `output` وملف `report.json` وأرسل الخطأ، ولا تصلح المنح يدوياً بالتخمين.

بعد التحقق افتح رابط وصل لفاتورة مختلطة: طرد عادي، حبات مفردة، وطرد مشكّل. يجب أن ترى مثلاً «2 طرد (10 باكيت)» و«3 باكيت» و«1 طرد مشكّل (2 نكهة أ + 3 نكهة ب)»، والمبلغ الأصلي نفسه. جرّب الطباعة والمشاركة وإعادة فتح الرابط من الهاتف والكمبيوتر.
