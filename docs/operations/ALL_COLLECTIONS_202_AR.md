## أمر المالك بعد التسليم

من checkout main بعد دمجPR5 واجتيازFULLCI لنفسSHA:

```powershell
Set-Location C:\Users\TOP\mahdi-admin
node scripts/operations/frankfurt-owner-upgrade202.mjs --dry-run
```

هذا فحص ملفات محلية محفوظة فقط، بلا اتصال مستضاف. بعد نجاحه ينفذ المالك
نفسه، من طرفية تفاعلية، عند استعداده للترقية:

```powershell
node scripts/operations/frankfurt-owner-upgrade202.mjs --apply
node scripts/operations/frankfurt-owner-upgrade202.mjs --verify-only
```

الأمر يقرأ الربط الخارجي المحفوظ ويطلب تأكيد الهدف وكلمة المرور تفاعلياً؛
لا تضع كلمة المرور في الأمر أوGit. يقبل السجل الكامل199 أو200 أو201 أو202
فقط، ويطبق الناقص بالتسلسل200→201→202؛ يسجل كل نسخة رسمياً بعد نجاحها.
لا --include-all، ولا backfill للفجوات، ولا تغيير لربط النسخ القديم في الجذر.
يقارن الكتالوج والصلاحيات و13جدولRealtime ويحافظ على تعليق الإشعارات
والمهام؛ إعادة الأمر بعد النجاح لا تكتب شيئاً. الانحراف غير المعتمد يوقفه.

أي نجاح لبروفة Docker أوالفحص المحلي ليس إثباتاً لحالة فرانكفورت الحالية.
لم ينفذ الوكيل apply/verify-only مستضافاً أوينشر واجهات أوEdgeFunctions.
