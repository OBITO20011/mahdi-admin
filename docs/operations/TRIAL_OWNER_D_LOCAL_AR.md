# الحزمة د: التحقق المحلي مكتمل وCI النهائي ينتظر

اعتمد المالك الشجرة و210 للقراءة فقط. اكتملت أزرار البيع الصريحة بالسعر والعداد المستقل، وبيان نوع كل سطر من الدليل المحفوظ. أصبح قالب الوصل مشتركاً بين نقطة البيع والسجل والرابط العام. طباعة الوصل ومشاركته من السجل لا تنشئ بيعاً أو دفعة أو حركة أو رابطاً جديداً. إعداد الطرد القديم من صنف واحد يبقى للقراءة والإيقاف فقط.

نجحت 1357 وحدة إدارة و197 وحدة متجر، وفحوص الأنواع وESLint الصارم والبناء المعزول وSEO. نجحت 20 حالة داخلية و6 للرابط العام على Chromium وWebKit. بقيت أدلة الحالات السابقة المتأثرة وPOS الفعلي (8) و5000 صنف (2) محفوظة. فحص تقسيم CI يغطي 1426 حالة بالهوية بلا فقد أو تكرار. دليل الوصول الحالي يربط 326 ملف مصدر و51 موقع استعلام و148 نجاحاً، و525 استدعاء RPC مع حالتي الرفض المتوقعتين فقط.

نجح 210 في 7 مجموعات DB فعلية: نفس STABLE والرمز والمنح، ورفض الروابط والحالات غير المتاحة، والأنواع الثلاثة ومكوّناتها المحفوظة، وعدم كشف تكلفة أو ربح أو معرّفات داخلية، والقراءة بلا كتابة، وفحص الدوال، والاستعادة الكاملة بلا اختلاف. تطابق البناء الجديد والترقية التدريجية: 172 migration و546 دالة و13 عضواً في Realtime. نجحت بروفة تطبيق وتسجيل 209 ثم210، وإعادتها بلا كتابة، ثم التصفير مع بقاء المالك وTOTP والمستودع وحذف ملفات التجربة والتحقق عبر REST.

حُفظ مرجع 210 محلياً ولم يتغير مرجعا 208 و209. دليل أوامر المالك: [TRIAL_OWNER_UPGRADE210_AR.md](TRIAL_OWNER_UPGRADE210_AR.md). لم يتصل الوكيل بفرانكفورت ولم ينفّذ أوامر مستضافة أو ينشر.

المتبقي قبل التسليم: الفحص النهائي للأسرار، وFULL41 لنفس SHA للدفع وPR16، ثم الدمج وقبول main CI. بعدها تبدأ ج من211 ثم هـ. نجاح التحقق المحلي وحده لا يعني اكتمال التسليم.
