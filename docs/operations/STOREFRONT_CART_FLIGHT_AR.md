# حركة الإضافة للسلة — متجر الزبائن فقط

الحركة زخرفة بعد نجاح مسار السلة القائم؛ لا تنتظرها الإضافة أو العداد أو الرسالة.
أزيل تأخير زر الإضافة السابق (680ms وقفل النقر أثناءه). خمس نقرات تحفظ خمس
إضافات؛ تطير ثلاث نسخ كحد أقصى، والباقي يكتفي بنطة الأيقونة.

- من بطاقة الصفحة: مسار Bezier مدته560ms، باستخدام Web Animations API فقط.
  يرسم canvas الصورة المعروضة نفسها دون عنوان صورة أو تنزيل جديد؛ وإن غابت
  الصورة تظهر دائرة بيج. لا قراءة أو تصدير لمحتوى canvas.
- داخل تفاصيل المنتج ومركّب الطرد: نطة فقط. يفضّل رأس الصفحة ثم أيقونة
  التنقل المرئية في الهاتف؛ إن غاب الهدف المرئي تُتخطّى الرحلة.
- `prefers-reduced-motion`: لا رحلة ولا نطة. لا تغيير للتركيز؛ العنصر
  `aria-hidden` و`pointer-events:none` وثابت خارج تدفق الصفحة.
- النجاح والإلغاء ومغادرة الصفحة/إخفاؤها تنظّف العناصر. غياب WAAPI أو فشل
  تحميل الوحدة لا يغيّر السلة. رسالة نجاح السلة الفعلية هي إعلان `aria-live`.
- لا استعمال في الإدارة أوPOS، ولا مكتبة جديدة أو طلب قاعدة جديد.

## التحقق والصيانة

```powershell
node scripts/testing/run-cart-flight-browser.mjs
npx.cmd tsx --test tests/cart-flight-contracts.test.ts
```

البوابة ضمن `quality`: Chromium وWebKit باللمس على360/390/1440، كتالوج وهمي
محلي وحارس شبكة. تختبر خمس إضافات قبل انتهاء الحركة، سقف3، النوافذ، تقليل
الحركة، الصورة الناقصة، الهدف المخفي، الإلغاء، WAAPI معطلة/فاشلة، ورفض
نفاد المخزون. تحفظ صوراً وفيديو وأرقام التوقيت خارج المستودع؛ يرفع CI الأدلة
الوهمية لمدة7أيام. لا بيانات محل أو شبكة مستضافة.

مقياس البداية هو بناء isolated لنفس main `f098f0af` ونفس السياق:
683725بايتJS خام،187840مضغوطة؛ بعد التعديل683323/187836. الوحدة الزخرفية
لا تطلب قبل الإضافة الأولى. ميزانية الأحجام والطلبات السابقة باقية كما هي.
لا ادعاء جديداً بتحقيق هدفLCP؛ قبِل المالك فرقLCP في حزمة السرعة السابقة.

اختبار AST يقارن دوال السلة الخمس مع main بعد محو وسيط DOM الاختياري
واستدعاءات الزخرفة فقط: تبقى الحسابات والحراس والكتابة والرسائل كما هي.
القراءات الحالية تختبر المصدر الفعلي؛ محو طبقة العرض بالبصمات الدقيقة مخصص
لأدلة السقوف التاريخية فقط، ويرفض أي فرق غير معروف.
