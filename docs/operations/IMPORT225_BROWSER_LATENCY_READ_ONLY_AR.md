# قياس زمن طلبات الاستيراد — تشغيل المالك فقط

هذا أمر **قراءة فقط** يجهّزه Codex ولا يشغّله على فرانكفورت. يشغّله المالك من متصفحه وشبكته الحقيقيين قبل D−1 أو خلال تحضيره، قبل نافذة القطع. لا يتطلب تعديل قاعدة أو إعداد أو صلاحية.

## الخطوات

1. افتح الإدارة المعتادة على جهاز وشبكة يوم القطع. إذا أردت قياس جلسة المالك، ادخل كالمعتاد واترك الجلسة صالحة.
2. افتح ملف [MEASURE_IMPORT225_GET_READ_ONLY.js](./MEASURE_IMPORT225_GET_READ_ONLY.js) واقرأه. انسخ محتواه إلى Console في أدوات المطوّر في صفحة الإدارة نفسها.
3. عند السؤال أدخل **مفتاح anon أو publishable العام** للمشروع. لا تدخل كلمة سر قاعدة البيانات ولا service_role ولا secret key. يُرفض المفتاح ذي الدور المرتفع قبل أي طلب.
4. اختر استخدام الجلسة الحالية إن أردت. تُقرأ في RAM من مفتاح Supabase القياسي للمشروع نفسه فقط. لا يُطبع access token ولا تُعدّل الجلسة ولا يُطلب تجديدها. إن تعذّر فهم تنسيقها أو انتهت، يتوقف الأمر؛ ادخل من التطبيق بالطريقة المعتادة ثم أعد القياس بقرارك. إذا لم توجد جلسة، يستعمل المفتاح العام.
5. انتظر 50 طلباً متسلسلاً ثم انسخ **سطر النتيجة التجميعية وحده** إلى تقرير D−1: samples وmeanMs وp50Ms وp95Ms وestimatedImportMinutes. لا تحفظ HAR أو رؤوس الطلبات؛ قد تحتوي الجلسة.
6. إذا ظهرت HTTP401/403 أو مشكلة CORS/CSP أو شبكة، يتوقف القياس بلا إعادة تلقائية. سجّل الكود والعدد المكتمل فقط؛ لا تغيّر سياسة المتصفح أو الصلاحيات لتجاوزها. لا يُنفَّذ استيراد بسبب نجاح القياس.

## ماذا يقيس؟

المسار ثابت للمشروع المعتمد، والطريقة GET فقط:

`/rest/v1/products?select=id&limit=1`

لا RPC، ولا POST، ولا refresh-token، ولا رفع صور، ولا كتابة إلى ملف أو localStorage، ولا نفق أو نشر. لا يتبع تحويلات HTTP، ولا يطبع الرابط الكامل أو المفتاح أو الجلسة أو صف المنتج أو أي حمولة.

الزمن من قبل fetch حتى قراءة JSON، ويشمل الكلفة التي يراها المتصفح. متوسط الخمسين يشمل الطلب الأول؛ p50/p95 بطريقة nearest rank. الاستجابة الفارغة مسموحة إذا كان RLS لا يعرض صفوفاً لـanon؛ قياس جلسة المالك أقرب إلى طلبات الاستيراد الفعلية.

الحساب المطلوب: **9438 × متوسط زمن GET ÷ 60000 = تقدير الدقائق**. مثال حسابي فقط: متوسط150ms يعطي23.60 دقيقة. هذه ليست مدة تشغيل مضمونة: الكتابات وSQL والأقفال وحجم الردود وExcel/React والمراجعة البشرية تختلف عن GET خفيف. لم يُنفَّذ أي قياس مستضاف بواسطة Codex.

الاعتمادات في الذاكرة طوال الأمر، وتُفرغ المراجع المؤقتة عند انتهائه؛ لا تمسّ الجلسة الأصلية المحفوظة للتطبيق. ينفّذ المتصفح اتصالاته الطبيعية؛ لا تصدّر سجله الشبكي ضمن الأدلة.
