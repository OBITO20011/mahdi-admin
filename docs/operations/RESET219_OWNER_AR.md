# RESET219 — التصفير والاستئناف الآمن

يُستخدم **بعد اعتماد الحزمة ودمجها وتطبيق 219**. المرجع الجديد `local-reference-through219-ready.json` يخص السقف 219 / 180 ملفاً. تبقى 218 محجوزة وغير موجودة؛ لا تعِد تسمية مرجع 217.

عقد الحفظ كما في [RESET217](RESET217_OWNER_AR.md): حساب المالك وMFA، وBR-MAIN/WH-MAIN، والوحدات والأقسام، وقيم `storefront_settings` المخصصة. تُستعاد الصفوف المحفوظة كنص خام، وتُقارن بصماتها. تُمسح أعمال التجربة وصورها وحساباتها الأخرى. لا يُحفظ سر Auth أو MFA في لقطة الاحتفاظ.

يفتح المالك PowerShell كـAdministrator يوم التشغيل، بعد النسخة الفاصلة والتحقق من الاسترجاع ووقف الكتابات والطلبات وناقل تنبيهات 217. الأمر هو `npm.cmd run frankfurt-owner-reset219 --`، ويتبعه الوضع المطلوب:

1. `--plan`: محلي، بلا اتصال؛ يتحقق من المرجع والأدوات، ولا يدّعي معرفة أعداد القاعدة الحية.
2. `--dry-run --owner-id UUID`: معاينة قرائية للأعداد الفعلية وما سيبقى وما سيُمسح.
3. `--apply --owner-id UUID`: بعد مراجعة المعاينة، مع عبارة التأكيد `RESET219 kzevmysfydaslxcerogt UUID` وكلمة قاعدة مخفية في الذاكرة.
4. عند انقطاع محاولة: افحص السبب، ثم `--resume --owner-id UUID` مع عبارة مختلفة: `RESUME RESET219 kzevmysfydaslxcerogt UUID`.

تُحفظ لقطة الاحتفاظ الخاصة وبصمتها وتُقرأ مجدداً قبل أول حذف، مع علامة `RESET219_IN_PROGRESS.json`. الاستئناف يعيد البناء كاملاً من الصفر: 180 ملفاً، ثم استعادة المحفوظ والتحقق الصارم. يُرفض عند وجود كتابات أعمال جديدة أو اختلاف المالك/المرجع أو فقد MFA. تُؤرشف اللقطة محمية ولا تُزال العلامة إلا بعد النجاح الكامل؛ لا كلمة مرور في argv أو Git أو التقرير.

مقارنة ما قبل/بعد إعادة البناء **حرفية داخل القاعدة نفسها ولكل المخططات**، مع ترتيب ACL فقط. لا تُحرّك أقسام Realtime بحسب يوم البداية والنهاية. ملفات `reset-catalog-before.json` و`reset-catalog-after.json` و`reset-catalog-differences.json` منقّحة؛ الحارس يقارن القيم الأصلية. النجاح: صفر فرق كتالوج وACL، وتاريخ 180 ملفاً، وعدادات نظيفة وبصمات محفوظ متطابقة. الفشل يبقى فشلاً.

الحاجز المؤقت في [خطة القطع](GO_LIVE_CUTOVER_AR.md) يمنع RESET217 واستئنافه قرب 00:00 UTC / 03:00 عمّان حتى يُثبت إصلاح UTC ويُدمج. لا تحوّل محاولة 217 غير المنتهية إلى 219؛ أكملها بمرجعها الأصلي أو توقّف لقرار المالك.
