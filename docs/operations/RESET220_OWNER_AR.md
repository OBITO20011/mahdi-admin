# RESET220 — تصفير تجربة وضع البيع المبسّط

**مسودة حتى اعتماد ودمج المرحلة3.** يتطلب قاعدة220 كاملة/181migration ومرجع220 الموافق للرأس.أدوات219 وملفاتها محفوظة،ولا تحول محاولة219 أو لقطة احتفاظها إلى220.218 محجوزة.

العقد:حساب المالك وAuth/MFA وBR-MAIN/WH-MAIN والوحدات والأقسام وقيم storefront_settings تبقى بنفسUUID وبصمات القيم الخام. تُمسح أعمال التجربة وصورها وحساباتها الأخرى،بما فيها الجداول الخاصةsales_lite1 وsales_lite2؛يُعاد seed الوضع الكاملON كما في البناء،ثم يختار المالك OFF قبل إدخال البيانات الحقيقية.

## بعد النسخة الفاصلة والاسترجاع والبروفة عليها أثناء تجميد الكتابات

يفتح المالك PowerShell كـAdministrator عند الإجراء الحي المأذون،من الإصدار المقبول:

```powershell
npm.cmd run frankfurt-owner-reset220 -- --plan
$ownerUuid = Read-Host "UUID حساب المالك المحفوظ"
npm.cmd run frankfurt-owner-reset220 -- --dry-run --owner-id $ownerUuid
npm.cmd run frankfurt-owner-reset220 -- --apply --owner-id $ownerUuid
```

Plan محلي بلا اتصال ولا أعداد حيّة. dry-run قرائي. apply يطلب المرجع والهوية المؤكدين وكلمة القاعدة في مطالبة مخفية وعبارة `RESET220 <project> <UUID>`؛لا كلمة مرور في argv أو الملفات أو Git.الـpooler والمشروع والمنفذ والمنطقة محكومة بأداة المالك الأصلية،ولا يوجد URL اعتباطي.

**نقطة بدء الإتلاف:** تفريغ Storage،ثم إسقاط الكائنات العامة ومخططيlite بعد كتابة وإعادة قراءة لقطة الاحتفاظ المحمية.قبلها يتوقف إن غابتpg_cron أو اختلف إصدارها/مالكها/schemaعن المرجع.ثلاث عباراتCREATE pg_cron التاريخية المعروفة وحدها تُستبدل بتحقق قرائي في RESET فقط؛الملفات والبصمات والتاريخ لا تتغير،والبناء من الصفر لا يتغير.

## عند انقطاع التنفيذ

تبقى الكتابات مغلقة.يجب الوصول إلى `RESET220_IN_PROGRESS.json` واللقطة المحمية ومفتاح الأرشيف من جهاز التنفيذ البديل؛لا تُنشأ علامة أو لقطة يدوياً.لا تستبدل المرجع ولا تستخدم عدّةD−1 أثناء المحاولة.راجع السبب ثم:

```powershell
npm.cmd run frankfurt-owner-reset220 -- --resume --owner-id $ownerUuid
```

العبارة مختلفة: `RESUME RESET220 <project> <UUID>`.يُعاد البناء كله181ملفاً بنفس المرجع واللقطة.غيابMFA/هوية مختلفة/مرجع مختلف/لقطة متغيرة/أي كتابة أعمال لاحقة،بما فيها الجداول الخاصة،يمنع الاستئناف؛التصعيد لخطة الدفتر،وليس تجاوز الحارس.نافذة التصفير **والاستئناف والاحتياط** بعيدة عن03:00عمّان/00:00UTC.
