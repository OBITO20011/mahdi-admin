# ترقية المالك إلى212 — الحزمة ر

هذه الأوامر للمالك بعد تسليم الحزمة ودمجها. جهّز الوكيل المرجع والأداة محلياً فقط؛ لم يتصل بفرانكفورت ولم ينفّذ الترقية عليها. أفاد المالك أن211 وملف ACL211 متحققان بنجاح.

212 للقراءة فقط: أسماء أطراف حركات الصندوق وملخص أصناف البيع وهوية المستند، الصور والرصيد غير المالي لاختيار أصناف المورد والتالف، وسجل التالف المرقّم والمفلتر. لا يغيّر كتابة أو حساباً أو مخزوناً أو ذمة أو درجاً أو صلاحية. قيم التالف في بيانات المالك وحده؛ admin يسجّل التلف فقط ولا يقرأ سجل208.

من PowerShell على جهاز أدوات المالك، استخدم worktree الحزمة الذي سيُطابق main بعد الدمج. النسخة الرئيسية القديمة تحتوي تعديلات محفوظة؛ لا تحتاج نقلها أو استبدالها لتشغيل الأمر:

```powershell
Set-Location C:\Users\TOP\.codex\worktrees\trial-owner-r\mahdi-admin
npm.cmd run frankfurt-owner-upgrade212 -- --dry-run
```

المتوقع: `ok: true` و`remoteWriteAttempted: false` وخطة `pending: ["212"]`. هذه مقارنة بين المرجع211 المحفوظ محلياً ومرجع212، ولا تقرأ حالة فرانكفورت الحالية. يجب وجود الملفين `local-reference-through211-ready.json` و`local-reference-through212-ready.json` في مجلد أدوات المالك. المراجع القديمة محفوظة دون استبدال.

بعد نجاحها، شغّل بنفسك:

```powershell
npm.cmd run frankfurt-owner-upgrade212 -- --apply
```

المتوقع: يتحقق من سجل كامل حتى211 ومن الكتالوج قبل أي تطبيق، ثم يطبق ويسجّل212 وحدها؛ إعادة الأمر بعد نجاح212 لا تعيد تطبيقها. النجاح `ok: true` و`catalogUnexpectedDifferenceCount: 0` و`alignmentCommands: 0`. لا يمنح صلاحيات ولا يصلح فروق ACL تلقائياً؛ أي فرق غير متوقع يوقفه ويُحفظ في التقرير. عند الفشل احتفظ بمسار التقرير وتوقف.

ثم:

```powershell
npm.cmd run frankfurt-owner-upgrade212 -- --verify-only
```

المتوقع: `ok: true`، سجل حتى212 وفروق غير متوقعة0، دون تطبيق migration أو تنفيذ إجراء مالي. لا تُعاد عمليات التالف القديمة ولا تُلغى تلقائياً؛ الإلغاء أو التحويل يتمان فقط بطلب المالك ومعاينة العقود208/211 القائمة.

بعد الترقية، افحص من الواجهة تفاصيل حركة بيع/مورد، والبحث برمز صنف مع اختفائه من القائمة، ثم سجل التالف من حساب المالك وحساب المدير. يظهر للمالك مبلغ «الخسارة عند التسجيل» كقيمة الحدث الأصلي؛ العكس أو التحويل لهما حالة واضحة مستقلة، وليس ذلك مجموع خسارة صافي الربح الحالي.
