الأمر يقرأ ملف SQL المراجع من المستودع ويرسله مباشرة إلى psql داخل معاملة واحدة. لا يلزم لصق الملف الكبير في SQL Editor. هو إصلاح منح فقط؛ لا migration جديدة أو إعادة تطبيق212، ولا تغيير لكتابة أو حساب أو بيانات عمل أو default privileges.

بعد دمج PR ونجاح CI الكامل على main، شغّل من النسخة الرئيسية المحدّثة على جهازك. نفّذ كل خطوة بعد نجاح السابقة.

```powershell
Set-Location C:\Users\TOP\mahdi-admin

```

ثم شغّل بنفسك:

```powershell

```

سيطلب كتابة `kzevmysfydaslxcerogt` بالضبط، ثم كلمة مرور قاعدة البيانات بإدخال مخفي. تبقى كلمة المرور في ذاكرة العملية وبيئة psql المؤقتة فقط، ولا تدخل الأوامر أو الملفات أو التقرير.

قبل أول REVOKE يتحقق من PostgreSQL17 ودور postgres، وقفل الترقية734151139، والسجل174migration حتى212، وهوية كل556دالة و119علاقة ومالكيها وإعداداتها وأجسامها وبنيتها ومنحها وبياناتها الوصفية. يسحب الزيادات المعروفة فقط، ثم يعيد التحقق قبل COMMIT. لا يمنح صلاحية جديدة، ولا يسحب service_role أو PUBLIC الموجودتين في المرجع. منح orders SELECT وجداول push تبقى كما هي.

المتوقع عند النجاح:

- `ok:true` و`commitConfirmed:true`.
- `rows:675` و`matches_reference_true:675` و`matches_reference_false:0`.
- `removed_privileges:432` إذا لم يُصلح شيء سابقاً، أو أقل لإصلاح جزئي، أو صفر عند إعادة تشغيل ناجحة.
- `report.json` للملخص و`rows.json` لهوية كل صف ونتيجته داخل مجلد التقرير.

أي اختلاف غير مراجع أو غياب منحة مرجعية أو فشل postcondition يرفض المعاملة. لا توجد إعادة محاولة تلقائية. احتفظ بمسار التقرير عند الفشل. إذا انقطع الاتصال لا تفترض هل وصل COMMIT؛ التقرير يميّز محاولة التنفيذ من تأكيد نجاحها، وإعادة التشغيل المحروسة آمنة بعد مراجعة النتيجة.

## أدلة الاختبار وحدودها

اختبارات الأمر تغطي تأكيد المرجع قبل كلمة المرور، ومعاينة بلا اتصال، وسرية تقارير الفشل، وسلامة نتائج675صفاً، ورفض مدخلات اتصال/SQL/كلمة مرور من flags. الاختبار الفعلي في PostgreSQL معزول يستخدم العامل نفسه؛ يثبت رفض التزامن والتغيير غير المراجع والتراجع بعد كل264REVOKE، ثم675نتيجة صحيحة وإعادة تشغيل بلا سحب، مع ثبات بيانات العمل والتسلسلات ومنح push وorders.

كشف الاختبار الفعلي أن JSON القديم قرّب الحد الأقصى لتسلسلات bigint. أصبح الحارس يحفظ ميتاداتا الحدود كنصوص عشرية دقيقة، وفق الحدود الافتراضية المثبتة في migrations الأصلية، ويرفض اختلافاً بمقدار1. جمل السحب وأهدافها لم تتغير؛ لا تعديل لأي sequence أو قيمته في أمر المالك. بقي المرجع212 المحفوظ كما هو، وتغيّرت بصمة ملف الحارس إلى `040a218eec0e557bebb0c6aeff0d0df12c07a1d6527dd5a16e1c8bbc7857c2e8` بالـLF القياسي.

التطبيق على فرانكفورت والتحقق منها ينجزهما المالك. الوكيل يشغّل dry-run واختبارات معزولة وCI فقط؛ لا اتصال بفرانكفورت أو نشر.
