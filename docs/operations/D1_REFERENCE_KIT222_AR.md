1. من جذر المستودع: `.\scripts\operations\d1-reference222-kit.ps1`. لا يلزم Administrator لهذا الأمر. يتوقف عند فرع/رأس/شجرة غير معتمدة أو CI غير مثبت. يبني محلياً على Docker معزول مرشحاً جديداً خارج المستودع؛ لا يلمس المرجع المثبت.
2. المطلوب:222/182،683دالة عامة و39خاصة،13Realtime،فحص الوصول بلا أخطاء، و`fresh-incremental-differences.json=[]`. كتالوج220 يبقى مطابقاً بعد استبعاد الدوال الأربع الجديدة فقط، مع حصر ملف ACL التاريخي في الدوال الأربع المعتمدة. لا تعادل عام بين NULL وACL الافتراضية.
3. راجع `approval.json` وورقة الاعتماد العربية. وقّع SHA المرشح الكامل مع SHA main وبصمات أداة RESET222 والنواة والوصول والتبعيات. مرشح الاختبار المحلي أو رأس PR ليس مرجع يوم التشغيل المعتمد. أي تغير رأس/مصدر/بصمة يستلزم تجهيزاً واعتماداً جديدين.
