من 2729 تشغيلاً مكتشفاً، قيس كل 1884 تشغيل مكتمل وغير متخطّى: 20606 وظائف منفّذة، بلا سجلات ناقصة أو معرّفات مكررة. مجموع وقت runners **148,452.133 دقيقة**. عند تقريب كل job إلى دقيقة للأعلى يصبح **159,442 دقيقة** لعينة المدد نفسها في سيناريو الخاص. يشمل القياس الفاشل والملغى إن استهلك runner؛ لا يشمل jobs المتخطّاة أو إعادة تشغيل run أُنشئ قبل أكتوبر.

## التخفيف في PR47

1. الجودة الكاملة والاسترجاع الاختباري يبقيان على PR وmain والتشغيل اليدوي.
2. يحذف تشغيلهما المكرر عند دفع فروع `codex/**`. دفع فرع بلا PR لا يثبت بوابة جودة؛ يجب فتح PR وانتظار كامل الفحص قبل الاعتماد.
3. `concurrency` لكل PR/ref يلغي التشغيل القديم المستبدل فقط؛ آخر SHA يجب أن يكمل كل البوابات.
4. فحوص الأسرار تبقى على push وPR. لا تغيير لأي job أو مصفوفة أو حالة اختبار أو assertion أو timeout أو retry أو صورة runner أو بوابة FULL، ولا تفعيل `PRIVATE_CI_BUDGET_MODE`.

بإسقاط تشغيلات الفروع المكررة من **العينة نفسها**: توفير **73,830 دقيقة، أي 46.305%**؛ تبقى **85,612 دقيقة مقربة**. توفير concurrency الإضافي غير مقاس، فلم يُضف. هذا تقدير لعينة العمل السابقة، وليس وعداً بدقائق شهر لاحق.

## المقارنة بحد 2000 دقيقة

حتى بعد حذف التكرار، **85,612 أكبر من 2000** لنفس معدل عمل العينة. لذلك لا يناسب نقل CI الكامل إلى مستودع خاص بهذه الحصة. لا تُحذف بوابة main أو تنقل الاختبارات الإلزامية إلى الليل لتلائم الميزانية. تبقى مراجعة تحسين المراجع أو caching أو وتيرة التطوير عملاً لاحقاً مع الحفاظ على البوابات.

التقدير الأولي القديم للنسخ وحده، 330–520 دقيقة شهرياً، كان افتراضاً غير مقاس وغير منفّذ، ولا يثبت ميزانية runner خاص. أُجّل هذا المسار؛ لا تنطبق عليه أوامر تفعيل في هذه الحزمة. تحويل مستودع أو إدخال أسرار يحتاج قراراً جديداً.
