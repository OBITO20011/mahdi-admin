## التخفيفالصغير داخلPR47

- الجودةالكاملة والاسترجاعالاختباري يبقيان علىPR وmain وmanual.
- يُحذفpush الفروع المكرر لهما؛لا يُحذف أيjob أوassertion أوحالةاختبار.
- concurrency لكلPR/ref يلغيالنسخةالمستبدلة،مع إبقاءآخرSHA تحتالفحص.
- فحوصالأسرار تبقى لكلpush وPR. لا تغييرللوقتالمسموح أوإعاداتالاختبارات
  أوصورrunners أوبوابةALL FULL أوuptime. لا يُفعّلPRIVATE_CI_BUDGET_MODE.
