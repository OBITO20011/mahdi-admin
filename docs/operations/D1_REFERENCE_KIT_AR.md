# عدّة D−1 — مرجع RESET219 للاعتماد

الأمران محليان، ولا يحتاجان Administrator. Docker وNode وتبعيات المشروع يجب أن تكون جاهزة. GitHub يُقرأ للتحقق من main وCI فقط؛ لا اتصال بفرانكفورت أو Supabase مستضاف، ولا RESET ولا نشر. يعمل التجهيز من main المحدث المعتمد؛لا تدمج #58 إلا يوم القطع حسب البطاقة.58/79/82 تبقى مسودات حتى قرارها.

## 1. تجهيز مرشح — بلا تثبيت

من المجلد الأساسي بعد سحب main بأمان وحفظ ملفات المالك:

```powershell
.\scripts\operations\d1-reference-kit.ps1
```

يتحقق من الفرع والرأس المحلي وorigin/main وmain على GitHub، ومن أحدث تشغيل CI كامل والأسرار والنسخ على الرأس نفسه. تُرفض التعديلات غير المعروفة أو staged؛الملفات المحلية العشرون المعروفة تقبل فقط ببصماتها المسجّلة فيd1-known-owner-files.json.لا تُقرأ قيم .env،ولا تُعدَّل. أي تغيير مشروع على هذه الملفات يحتاج مراجعة وتحديث البصمات؛لا تنشئ قائمة سماح تلقائية لتجاوز الرفض.

عند تعذّر GitHub أو rate limit: يتوقف الأمر برسالة D1_CI_UNVERIFIED_MANUAL_REVIEW_REQUIRED. يراجع المالك تشغيلات SHA نفسه يدوياً ويؤكدها مع المطوّر؛لا يوجد --skip-ci أو اعتماد ضمني. يبقى التجهيز الآلي متوقفاً حتى يعود التحقق المقروء أو يعتمد المالك مساراً آخر مستقلاً.

يبني 217 ثم219 ويقارن219النظيف بالأداة المعتمدة بلا تعديلها،ويعيد readReady219Reference. يحفظ داخل مجلد جديد مؤرخ تحت %USERPROFILE%\NawasrahFrankfurt\D1-candidates: المرشح،build-report.json،fresh-incremental-differences.json=[]،approval.json،واعتماد-مرجع-D1.md من صفحة واحدة. يسجّل SHA main وبصمات المرشح ودليل الوصول وRESET219 والنواتين وحارسcron وكل التبعيات،مع روابطCI وحقل توقيع.لا يلمس المرجع الحالي ولا مجلدnawasrah-fra-001-138.

حقل التقرير: **التوقيع: __________ التاريخ: __________ القرار: قبول / رفض**. يراجع المالك التقرير والبصمة الكاملة ويوقّع: يعتمد الملف بعينه على الرأس والمصادر المذكورة فقط؛هذا ليس إذناً بالتصفير أو النشر. إذا تغيّر main أو مصادر الوصول،جهّز مرشحاً جديداً.البصمة التاريخية A915… لم تعد صالحة على المصادر الحالية (157→181فحص وصول).

## 2. تثبيت مستقل — بعد موافقة المالك فقط

```powershell
$candidate = Read-Host "مسار المرشح الذي اعتمده المالك"
$approvedSha = Read-Host "SHA-256 الكامل من تقرير الاعتماد الموقّع"
.\scripts\operations\d1-reference-install.ps1 -Candidate $candidate -ApprovedSha256 $approvedSha
```

يشترط نفسmainوالمصادر وبصمة64خانة،ويُعيد جاهزية المرشح. يرفض أي RESET219_IN_PROGRESS.json؛لا تثبيت أثناء محاولة تصفير قائمة أو resume:الاستئناف يحتفظ بمرجعه ولقطته الأصليين.يحفظ نسخة .before-D1-* من الهدف الحالي وبصمتها،وينسخ عبر .incoming-* مثبت البصمة،ثم يستبدل ذرياً ويطابق البصمة ويعيد readReady219Reference على الهدف.فشل الجاهزية بعد الاستبدال يعيد البايتات السابقة؛تُحفظ نسخة السابق وسجل التثبيت.لا يمس أي مرجع آخر أو ربطSupabase.شغّل التجهيز والتثبيت بعيداً عن أي محاولةRESET؛لا تترك جلسة تنفيذ أخرى تعمل عليه.

الهدف الافتراضي: %USERPROFILE%\NawasrahFrankfurt\nawasrah-fra-001-138\local-reference-through219-ready.json.تغيير المسار للاختبارات المحلية فقط يكون بـ-Workdir؛لا تقبل روابطjunction/symlink في مسار التثبيت.لا تستخدم الملفات .incoming-* كمرجع.
