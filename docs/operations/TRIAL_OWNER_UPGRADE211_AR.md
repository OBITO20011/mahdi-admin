# ترقية المالك حتى211 — مرشح قيد التحقق

هذا الدليل جاهز للمراجعة. اعتماده للتشغيل بعد دمج الحزمة ج ونجاح CI على
main وتثبيت المرجع المحلي211. أمر المالك الحالي حتى ذلك الحين210.
لم يتصل الوكيل بفرانكفورت ولم ينفذ هذه الأوامر عليها.

بعد تسليم الحزمة ج، افتح PowerShell وشغّل الخطوات بالترتيب من الكمبيوتر
الذي يحوي أدوات المالك ومراجعه المحلية:

```powershell
Set-Location C:\Users\TOP\mahdi-admin
git pull --ff-only
npm.cmd run frankfurt-owner-upgrade211 -- --dry-run
```

المتوقع: `ok: true` و`remoteWriteAttempted: false`. هذه مقارنة محلية فقط
بين المرجع المحفوظ208 والمرجع211، فلا تتصل بفرانكفورت ولا تقرأ حالتها
الحالية. قد تعرض قائمة209 و210 و211 بوصفها خطة من المرجع208، حتى لو كنت
قد طبقت بعضها بالفعل على فرانكفورت. لا تتوقع أن تكون هذه القائمة كشفاً
مباشراً بالمطبّق على القاعدة المستضافة.

عند نجاح الخطوة الأولى، شغّل بنفسك:

```powershell
npm.cmd run frankfurt-owner-upgrade211 -- --apply
```

المتوقع: يتحقق الأمر من سجل القاعدة وصلاحياتها ومرجع المرحلة الموجودة،
ثم يطبق ويسجل الناقص فقط من209–211. قاعدة حتى210 تحتاج211 وحدها؛ قاعدة
حتى208 تحتاج209 و210 و211. لا يُملأ أي فراغ تاريخي غير معتمد. النتيجة
الناجحة `ok: true` و`catalogUnexpectedDifferenceCount: 0`، مع حفظ تقرير
داخل مجلد أدوات المالك. إن فشل حارس أو ظهرت فروق غير متوقعة، توقف عند
التقرير ولا تعدّل SQL أو تمنح صلاحيات يدوياً لتجاوز الحارس.

ثم شغّل بنفسك:

```powershell
npm.cmd run frankfurt-owner-upgrade211 -- --verify-only
```

المتوقع: `ok: true`، وفروق كتالوج غير متوقعة0، وسجل حتى211. هذه الخطوة
تقرأ وتتحقق ولا تطبق migration أو تعيد تصنيف تالف. وجود211 لا يحوّل أي
حدث قديم تلقائياً؛ التحويل يطلبه المالك من الفاتورة بسبب ومعاينة.

211 تضيف ربط الاستبدال/التالف النهائي بالمعلّق لدى المورد. قيمة الحبة
التاريخية هي المعلّقة؛ يبقى فرق تكلفة البديل على الربح بقرار المالك. لا
تغيّر تسوية121 أو الدرج أو الذمم أو أسطر الفواتير القديمة.

وبقرار المالك، تسمح211 أيضاً بتبديل الحبة المعيبة من الطرد العادي ومن
صنف «طرد فقط» ومن مكوّنات المشكّل. البيع المفرد وردّ المال عن حبة من
الطرد يبقيان ممنوعين. يمكن إرجاع الطرد كاملاً بعد التبديل، وتُحتسب كل
حبة من الأصل أو البديل بتكلفتها التاريخية؛ لا تغيير لتسوية المال121.
