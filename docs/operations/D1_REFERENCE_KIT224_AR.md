# عدّة D−1 للسقف 224

هذه تعليمات ما بعد اعتماد الحزمة وإذن المالك، وليست إذناً بالترقية أو
التثبيت. جهّز المرجع واعتمده وثبّته قبل `--dry-run` للترقية224، في
مجلّد العمل نفسه. مرجع224 مستقل عن مراجع219 و220 و222 و223؛ لا تُستبدل
تلك المراجع يدوياً.

1. على `main` النهائي المطابق لـ`origin/main`، وبعد CI الكامل على الرأس
   نفسه، شغّل `scripts/operations/d1-reference224-kit.ps1`. لا Administrator
   مطلوب. ترفض الأداة الشجرة غير المعروفة أو اختلاف ملفات المالك المعتمدة،
   والفرع أو الرأس أو CI غير المطابق. فشل قراءة GitHub يعني التوقف للمراجعة؛
   لا يوجد تجاوز من سطر الأوامر.
2. تنتج الأداة مرشحاً جديداً خارج المستودع، ومقارنة بناء طازج/تدريجي فارغة،
   وتقرير اعتماد عربي وJSON ببصمات SHA-256 والرأس: **224/184 ملفاً،
   688 دالة عامة، 181 قراءة وصول و13 عضواً في Realtime**. لا تلمس المرجع
   الحالي. مرشح الاختبار غير قابل للاعتماد أو التثبيت.
3. يراجع المالك التقرير والجاهزية والبصمات ويوقّع المرشح المحدد. بأمر
   **منفصل**: `scripts/operations/d1-reference224-install.ps1` مع معاملات
   `-Candidate` و`-ApprovedSha256` كاملة من64خانة و`-Workdir` التي يعرضها
   دليل الأمر. يجب بقاء الرأس والمصادر وCI كما عند التجهيز.
4. يرفض التثبيت أي علامة RESET نشطة. يحتفظ بنسخة الهدف السابق وبصمتها،
   ويفحص ملف incoming قبل الاستبدال وبعده، ويعيد قراءة الجاهزية. أي فشل
   في الاستبدال يعيد الهدف السابق ببصمته؛ لا تُحذف العلامات لتجاوز الرفض.

بعد التثبيت، أكمل [حماية الترقية224](UPGRADE224_AR.md). قبل القطع تحقّق من
مطابقة الرأس النهائي وجدّد المرجع إذا تغيّر، ثم أثبت بروفة
[RESET224](RESET224_OWNER_AR.md) والنسخة الفاصلة.
