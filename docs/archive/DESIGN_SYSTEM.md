# نظام التصميم لنواصرة

## الهدف

واجهة عربية RTL عملية لمحل جملة، يكون الإجراء التالي واضحًا على هاتف الموظف ولا تتحول الإدارة إلى لوحة مزدحمة. التصميم يدعم سطح المكتب أيضًا، لكن ترتيب الأولوية هو شاشة الهاتف.

## مبادئ الواجهة

1. **مركز اليوم أولًا:** الطلبات الجديدة، التجهيز، التوصيل، الذمم والإجراء التالي تظهر قبل التقارير والإعدادات.
2. **رقم واحد مفهوم:** المبلغ دائمًا دينار أردني بثلاث منازل، والكمية المعروضة للموظف والعميل هي طرد جملة كامل.
3. **حالة قبل زر:** قبل الإجراء الخطير تظهر حالة المخزون/الوردية/التحصيل والنتيجة المتوقعة.
4. **لا حذف صامت:** الإلغاء أو العكس أو تسوية الجرد تحتاج سببًا وتأكيدًا واضحًا.
5. **الحساسية خارج المتجر:** لا تظهر تكلفة الشراء أو الربح أو بيانات المورد في موقع العملاء أو الإيصالات العامة.

## الهوية والألوان

| الاستخدام | اللون |
|---|---|
| الخلفية الإدارية | `slate-950` / `#020617` |
| بطاقات الإدارة | `slate-900` مع حدود `slate-800` |
| الإجراء الرئيسي | `blue-600` أو `indigo-500` |
| نجاح/تحصيل/متاح | `emerald-500` |
| انتظار/تنبيه | `amber-500` |
| خطر/عجز/إلغاء | `rose-500` |
| متجر العملاء | خلفية فاتحة، نص داكن، أزرق للهوية وأخضر للتوفر |

لا يحمل اللون وحده المعنى: كل حالة ترافقها تسمية عربية واضحة وأيقونة مناسبة.

## التخطيط والاستجابة

- إدارة الهاتف: عنوان قصير، محتوى قابل للتمرير، شريط تنقل سفلي ثابت وخطوة سريعة واحدة واضحة.
- الإدارة على سطح المكتب: نفس المحتوى يتسع إلى أعمدة من دون إخفاء الحقائق أو تغيير تسلسل العمل.
- المتجر: رأس خفيف، بحث، أقسام، سلة ثابتة وشريط تنقل سفلي على الهاتف.
- بطاقات المنتج تعرض فقط ما يحتاجه عميل الجملة: صورة، الاسم، القسم، نوع الطرد، سعر الطرد والتوفر.

## المكونات والسلوك

- `AppErrorBoundary` يعطي طريق تعافٍ واضحًا عند خطأ واجهة بدل شاشة بيضاء.
- الشاشات الثقيلة تُفتح عند الحاجة مع حالة تحميل عربية قصيرة.
- النوافذ والإجراءات الخطرة تستخدم تأكيدًا صريحًا ورسالة خطأ قابلة للتنفيذ.
- حقول الهاتف، المال، CliQ والموقع تملك تسميات واضحة واتجاه كتابة مناسبًا.
- الطباعة وPDF تستخدم CSS عربيًا من المتصفح؛ لا يوجد مولد PDF وهمي.

## إمكانية الوصول والجودة

- لغة الصفحة `ar` واتجاهها `rtl`.
- العناصر التفاعلية تعتمد أسماء مرئية أو `aria-label` حيث يلزم.
- لا يوجد تمرير أفقي مقصود على عرض هاتف قياسي.
- لا يُطلب الموقع أو الإشعارات أو البصمة إلا بعد اختيار المستخدم للإجراء.

هذا النظام ليس قالب iPhone تجميليًا فقط؛ هو قواعد عملية لتقليل أخطاء البيع والاستلام والتحصيل على شاشة صغيرة.
